# Booking Servis

Онлайн-сервіс бронювання житла: мандрівники шукають і бронюють житло, власники керують об’єктами, цінами та бронюваннями, адміністратор перевіряє власників і об’єкти.

## Технічний стек

- Backend: C#, ASP.NET Core, Entity Framework Core, PostgreSQL
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Оплата: Stripe (тестовий режим)
- Карти: MapLibre + OpenStreetMap
